使用流程

三步开始省钱

无需提交订单号，无需手动确认收货。全程在微信中完成，简单省心。

1

发送商品链接

将淘宝、京东、拼多多等平台的商品链接或分享文案，直接发送给微信机器人。

2

通过推广链接下单

复制机器人返回的优惠购买链接，在对应 APP 中完成购买。须通过该链接下单方可参与奖励统计。

3

收货后自动到账

确认收货后，系统定时自动同步联盟订单。推广奖励入账后会通知您，满额即可申请提现。

运营部署

为导购运营者打造的后台系统

基于 Windows PC 微信 + wxauto 自动化，配套完整管理控制台，适合个人或小团队运营返利导购业务。

管理控制台功能

  • 数据概览：用户数、订单数、佣金总额、待审提现
  • 用户管理：余额、订单历史、签到记录一键查看
  • 提现审核：在线审批/拒绝，余额自动退回
  • 联盟配置：淘宝/京东/拼多多 API 密钥管理
  • 佣金分成：灵活配置用户分成比例与最低提现额
  • 订单同步：手动触发联盟订单拉取与结算

部署特点

  • 微信通道：wxauto + PC 微信，私聊与群聊均支持
  • 零 Token 路由：常用指令规则匹配，响应快、成本低
  • SQLite 轻量存储：单服务器即可运行，运维简单
  • 安全隔离：API 仅监听 localhost，通过 SSH 隧道访问后台
